# Web Shop App

Этот проект представляет собой веб-приложение для интернет-магазина, реализованное с использованием Django. Включает страницы для отображения каталога товаров, а также контактную форму для обратной связи.

## Структура проекта

- **home.html** — главная страница сайта с каталогом товаров.
- **contacts.html** — страница с контактной информацией и формой для обратной связи.
- **views.py** — контроллеры для обработки запросов на страницы сайта (главная и контакты).
- **urls.py** — маршруты для страниц сайта.

## Установка и запуск

### 1. Клонируйте репозиторий

```python
git clone https://github.com/yourusername/web-shop-app.git
```

### 2. Установите зависимости

Перейдите в директорию проекта и установите зависимости с помощью `pip`:

```python
cd web-shop-app
pip install -r requirements.txt
```

### 3. Запустите сервер

Запустите сервер разработки Django:

```
python manage.py runserver
```

Перейдите в браузер и откройте `http://127.0.0.1:8000/` для проверки работы приложения.
